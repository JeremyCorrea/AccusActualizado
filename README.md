# Accus Solutions - Sitio Web

Este es el sitio web corporativo de Accus Solutions, expertos en Ingeniería Eléctrica, Construcción, Ensayos eléctricos en la Minería y Fibra Óptica.

## Mejoras Recientes Realizadas
- **Identidad Visual:** Integración del logotipo oficial en el encabezado y alineación precisa con el contenido principal.
- **Navegación:** Menú hamburguesa rediseñado, más estilizado y con efectos de sombreado gradual para un aspecto premium.
- **Optimización de Secciones:**
  - **Inicio:** Alineación de textos y botones.
  - **Nosotros:** Proporciones de imagen y texto ajustadas para mayor profesionalismo y simplificación de llamados a la acción.
  - **Servicios:** Mejora de legibilidad mediante sombras en descripciones y encuadre de página corregido.
  - **Contacto:** Actualización de fondo, tipografías y alineación de títulos para consistencia visual total.

## Tecnologías Utilizadas
- **Framework:** Next.js 15 (App Router)
- **Estilos:** Tailwind CSS & Shadcn/UI
- **Despliegue:** Firebase App Hosting (con despliegue automático vía GitHub)
- **IA:** Integración con Genkit para futuras funcionalidades inteligentes.

---
Para iniciar el servidor de desarrollo localmente:
```bash
npm run dev
```
